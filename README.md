## From Charts to Trends: How has Song Popularity Changed Over Time?

Status: In Progress

### About the project
This project explores how song popularity has changed over time and investigates the relationship between Tiktok music trends and Billboard Hot 100 chart performance. 

The goal is to examine whether songs trending on Tiktok also appear on the Billboard charts, how their chart position change, and whether older songs return to the charts after gaining popularity on social media. 

### Research Questions:
- How has song popularity on the Billboard Hot 100 changed over time?
- Do songs trending on Tiktok also appear on the Billboard Hot 100?
- Do older songs return to the Billboard charts after becoming popular on Tiktok?

### Tools and Technologies
- Python(pandas, data visualization)
- SQL
- Power BI / Tableau

### Data Sources
- Billboard Hot 100 Dataset - Kaggle
- Tiktok Trending Music Dataset - Hugging Face

### Note
This project aims to explore relationships between Tiktok trends and billboard chart performance. Any observed association will not be interpreted as proof of casuation.

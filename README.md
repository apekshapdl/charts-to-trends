# From Charts to Trends: How Has Song Popularity Changed Over Time?

**Status:** In progress — Day 5, TikTok and Billboard comparison. The historical Billboard analysis is complete as a first pass.

## Project

This project studies how songs perform on the Billboard Hot 100 and whether TikTok music trends overlap with Billboard chart appearances. It also looks for possible chart returns after long gaps. Any relationship found is descriptive and does not prove that TikTok caused a chart change.

## Research questions

- How has Billboard chart presence changed over time?
- Do songs in TikTok's seven-day Top 100 also appear on the Billboard Hot 100?
- Do songs return to Billboard after a long gap, and do any of those returns overlap with TikTok data?

## Data sources and setup

- Billboard Hot 100: Kaggle dataset, source file named `hot100.csv`.
- TikTok Trending Music: Hugging Face dataset `lingbow/tiktok-trending-hashtags-music`, source file named `trending_music.csv`.

The raw and cleaned datasets are excluded from Git. To run the notebooks, obtain the source files and place them here:

```text
data/raw/hot100.csv
data/raw/trending_music.csv
```

Install the notebook tools in your Python environment:

```bash
python -m pip install jupyter pandas matplotlib
```

Before sharing dataset files or derived data publicly, check the current license and terms for each source. The notebooks use relative paths. Start Jupyter with `notebooks/` as its working directory so `../data/` points to the project data folder.

## Notebook order

1. `data_exploration.ipynb` explores the source datasets.
2. `data_cleaning.ipynb` creates the cleaned files under `data/cleaned/`.
3. `03_data_analysis.ipynb` matches song names and aligns TikTok records to Billboard weeks.
4. `04_historical_trends.ipynb` examines long-term Billboard chart presence and possible returns.

The cleaned files are generated by the cleaning notebook and are also excluded from Git. Run that notebook before the analysis notebooks.

## Current findings

- Exact normalized title-and-artist matching confirmed 1,230 TikTok song IDs against Billboard history. Another 1,372 IDs matched by title only and remain unconfirmed.
- TikTok has complete seven-day coverage for 43 Billboard weeks in the shared date range. Among 1,859 confirmed TikTok song-weeks in those weeks, 152 also appear on Billboard in the same week.
- The historical analysis identified 2,784 song/artist credits with multiple chart runs and 196 later runs beginning at least ten years after the first observed Billboard appearance.
- Of 15 long-gap returns within the TikTok date range, 7 had an exact normalized title-and-artist match in TikTok. This is a preliminary name match, not evidence of a TikTok-driven comeback.
